# Design system

One shared base, with a theme for each product.

- **Foundations:** the colors, type, space and motion every theme is built from.
- **Components:** each one built on [React Aria Components](https://react-aria.adobe.com/) and styled with tokens only.
- **Patterns** and **Explorations:** bigger pieces and ideas being tried.

**Theme** in the toolbar picks the theme: Fireside, Sunrise or Spotlight. **All, side by side** shows every theme at once. **Mode** switches light and dark.

Component stories use plain labels, like "Button" and "Label", so they never belong to one product.
